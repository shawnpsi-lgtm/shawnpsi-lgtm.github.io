Web Audio DJ System

rx3

A pro DJ unit. Now it opens in a tab.

Two decks, a mixer and every effect from the Pioneer XDJ-RX3, rebuilt from the unit's own firmware. It sounds the same, sample for sample. No install. No server.

Every effect is the firmware's own code, rebuilt line for line in the browser. Then each one is tested against the real unit's output until they match exactly.
