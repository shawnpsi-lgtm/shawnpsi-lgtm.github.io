Architecture

How software like Yoink is created

Yoink.media is a paid Windows and Apple Silicon app from Tabs Labs. You type a spoken phrase, it finds internet clips where that line is said, and you drag the audio into a DAW. The landing page is not the product. The product is a desktop sample hunter sitting over Ableton.

What the public site tells you

The marketing site is static HTML on Cloudflare. A worker injects geo and an A/B price (around $30–$35), Stripe Embedded Checkout takes payment, and PostHog (proxied at a Tabs Labs host) measures the funnel. Brazil is geo-blocked. Discord is shown in some regions. None of that is how the sampler works. It is how the sampler is sold.

The four moving parts

  1. 01 · Index

    Search timed speech, not filenames

    A phrase hunter needs captions or transcripts with timestamps. Commercial tools usually query a huge caption index (YouTube search + timedtext is the common pattern people infer from the UI: language, country, category, Creative Commons, view counts). Hits come back as “this video said that line at 00:14.” The fragile dependency is the caption source staying available.

  2. 02 · Cut

    Turn a timestamp into a WAV

    The backend (or a local helper) fetches the audio stream, then ffmpeg cuts a few seconds around the caption. Waveform peaks are computed from PCM so the card can show a blue trace and two flags. Loading bars in the Yoink UI are this step happening per result.

  3. 03 · Shell

    Wrap it so a DAW can catch the file

    Windows and Apple Silicon builds, a floating window, History and Settings, drag from the card. Electron’s startDrag or the native NSPasteboard / Win32 drag APIs are what make “drag it into Ableton” work. A VST is optional; Yoink presents as a standalone window, which is simpler than plugin hosting.

  4. 04 · Commerce

    Sell the binary, measure the page

    Stripe Embedded Checkout, regional price tests, and analytics live on the website. License delivery is a download for Mac/Windows. Geo blocks and Discord are distribution choices, not sampler technology.

Why it is a desktop app

DAWs accept OS file drags. A website can download a WAV, and Chromium can sometimes drag a File object to the desktop, but dropping onto Ableton Live is reliable only when the app hands the OS a real path. That is the usual reason these tools ship as Electron, Tauri, or a native wrapper with a web UI inside: the search UI is HTML, the drag is native. Yoink’s window chrome, filter grid, and waveform cards are a web UI in a desktop frame.

What Sayclip now runs

Web mode queries a public caption index, receives exact YouTube timestamps, resolves an allowed audio stream, and asks FFmpeg for only the matching range. The result is cached as a WAV for preview, download, and drag. If YouTube requires authentication or blocks the server IP, the app reports that restriction and supports an operator-provided cookies file; it does not bypass the restriction.
