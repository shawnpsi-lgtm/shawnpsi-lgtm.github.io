Endpoints

GET/api?q=your question

Answers a question about Shawn, grounded only in what's on this site.

curl "https://groq-chat.shawnpsi.workers.dev/api?q=where+does+shawn+work"

{ "answer": "Shawn is a Data Scientist at C3 AI..." }

GET/api

Everything on the site as one block of text, for your own model to read. No limit.

{ "name": "Shawn Singh", "content": "SHAWN SINGH — data + design...", "usage": "..." }

MCP/mcp

An MCP server with one tool, about_shawn. Add the URL as a connector in Claude, Cursor or any MCP client.

https://groq-chat.shawnpsi.workers.dev/mcp

CLI

A one-file shell script around the API. Needs only curl. Install:

sudo curl -fsSL https://shawnsingh.me/shawn-ai -o /usr/local/bin/shawn-ai && sudo chmod +x /usr/local/bin/shawn-ai

Then ask away:

shawn-ai "where does shawn work?"

Rather not install anything? Add &plain to any API call to get bare text back:

curl "https://groq-chat.shawnpsi.workers.dev/api?q=where+does+shawn+work&plain"

Limits

3 questions per minute per IP, 800 characters per question, one question at a time (no chat history). Over the limit you get a 429 with { "error": "..." }. It runs on a free tier, so on busy days it may be rate-limited for everyone.
